# SketchView

SketchView utilizes high-performance rendering to deliver real-time visualization and auto-zooming capabilities via a scalable system API.

SketchView is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/innayakendya/SketchView.git`
2. `cd SketchView`
3. Install in editable mode: `pip install -e .`

## Configuration

SketchView is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
